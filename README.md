# 🔄 Unit Converter

A responsive web application for converting length and weight units.

## Features

- Convert length units: meters, feet, kilometers, and miles.
- Convert weight units: kilograms, pounds, grams, and ounces.
- Select source and destination units.
- Swap units with one click.
- Automatically update results when values or units change.
- Validate numeric input.
- Display results rounded to a maximum of six decimal places.
- Responsive design for mobile and desktop.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- index.html — Page structure
- style.css — Styling and responsive layout
- script.js — Conversion logic

## How to Use

1. Choose Length or Weight.
2. Enter the value.
3. Select the source and destination units.
4. Click Convert to view the result.
5. Use Swap Units to reverse the conversion.
